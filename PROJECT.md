## 1. PROJECT OVERVIEW

### What This Project Is
A complete **sound therapy & meditation app** that runs as:
- 🌐 **Web app** (single HTML file, ~612 KB)
- 📱 **Android app** (real native APK via Capacitor)

### Tech Stack
| Layer | Technology |
|-------|-----------|
| **UI Framework** | React 19 + TypeScript |
| **Styling** | Tailwind CSS 4 |
| **Build Tool** | Vite 7 |
| **Animation** | Framer Motion |
| **State** | Zustand |
| **Audio** | Web Audio API (procedural synthesis) |
| **Native Wrapper** | Capacitor 8 |
| **Charts** | Recharts |

### Features
- 🐦 **88 unique bird voices** (procedurally synthesized)
- 🌌 **61 curated soundscapes** (mood-based environments)
- 🎵 **23 healing tones** (Solfeggio + Chakras + Binaural beats)
- 🙏 **10 sacred mantras** from all religions (Hindu, Buddhist, Sikh, Christian, Islamic, Native)
- 🪈 **Krishna's Bansuri Flute** in Raga Yaman
- 🦁 **Wild animals** (Lion, Tiger, Elephant, Wolves, Deer, etc.)
- 🏔️ **Mountain sounds** (Tibetan horns, yak bells, cave drips, avalanches)
- 🎭 **14 mood categories** (Calm, Happy, Sleep, Focus, Sacred, Wild, etc.)
- 🧪 **Smart Sound Lab** with auto-tagging & custom mix builder
- 💾 Custom mixes saved to local storage
- 📊 Session history with charts
- 🔋 Android: Keep screen awake during meditation
- 📳 Android: Haptic feedback

## 3. EVERY FILE EXPLAINED

### 🔴 Critical Core Files

| File | Lines | What It Does |
|------|-------|--------------|
| **`src/data.ts`** | ~1100 | The brain — all 88 birds, 61 environments, 23 tones, 14 moods defined here |
| **`src/audio/engine.ts`** | ~1500 | The heart — Web Audio synthesizers for every sound type (birds, mantras, instruments, wildlife) |
| **`src/types.ts`** | ~120 | All TypeScript types — keeps the codebase safe |
| **`src/store.ts`** | ~120 | Zustand store — current screen, mood, mix, sessions persist to localStorage |
| **`src/App.tsx`** | ~30 | Routes between 7 screens based on store state |
| **`src/main.tsx`** | ~15 | Mounts React + initializes native Android features |

### 🟢 UI Components (All in `src/components/`)

| File | What It Does |
|------|--------------|
| **`MoodScreen.tsx`** | Home screen — beautiful grid of 14 mood cards. Stats banner. Custom mixes section. |
| **`EnvironmentsScreen.tsx`** | Browse soundscapes for selected mood. Shows ingredient layers. |
| **`NowPlayingScreen.tsx`** | Player with timer, layer mixer (live volume sliders), wave visualizer, master volume |
| **`BirdsLibraryScreen.tsx`** | Browse all 88 birds. Filter by region. Tap to preview each one. |
| **`SoundLabScreen.tsx`** | Smart sound mixer — search, filter by mood/freq/tempo/energy, build & save custom mixes |
| **`HistoryScreen.tsx`** | List of past sessions with mood badges and durations |
| **`SettingsScreen.tsx`** | Volume defaults, export CSV, clear history |
| **`WaveVisualizer.tsx`** | Canvas-based animated orb that pulses with the audio |

### 🔵 Audio System

| File | What It Does |
|------|--------------|
| **`engine.ts`** | The audio engine. Defines synthesizers for: birds (8 patterns), rain, fire, wind, ocean, all instruments (bowls, gongs, hang drum, didgeridoo, tanpura, sitar, flutes), mantras (vocal formant synthesis), wildlife (lions, tigers, etc.), Krishna's bansuri |
| **`tagger.ts`** | Auto-tagging system — every sound gets `mood`, `freqBand`, `tempo`, `energy` tags. Used by Sound Lab for smart filtering. |

### 📱 Native Integration

| File | What It Does |
|------|--------------|
| **`src/native/capacitor.ts`** | Wraps all Capacitor APIs (keep-awake, haptics, back button, splash screen). All functions are no-ops on web — same code works on both platforms. |
| **`capacitor.config.ts`** | Capacitor configuration — app ID `com.calmnature.app`, app name "CalmNature", splash & status bar settings |

### 🛠️ Scripts (in `scripts/`)

| File | Purpose | When to use |
|------|---------|-------------|
| **`setup-android.sh`** | Installs deps → builds web → adds Android platform → syncs | Run ONCE to convert to Android |
| **`download-sounds.mjs`** | Downloads bird MP3s from xeno-canto | Optional — only if you want to add real recordings later |
| **`process-audio.sh`** | FFmpeg pipeline (normalize, trim, fade) | Optional — only if you have real MP3s |
| **`analyze-audio.mjs`** | Auto-tags MP3s by analyzing audio features | Optional — only with real recordings |

### 📦 Configuration Files

| File | Purpose |
|------|---------|
| **`package.json`** | NPM dependencies (React, Capacitor, Framer Motion, etc.) |
| **`tsconfig.json`** | TypeScript compiler settings |
| **`vite.config.ts`** | Vite build (uses single-file plugin → bundles everything into one HTML) |
| **`index.html`** | Page template — title set to "CalmNature" |

## 6. CONVERT TO ANDROID — FULL GUIDE

### 📋 Prerequisites Setup (one-time, ~1 hour)

#### A. Install Node.js
1. Download from https://nodejs.org (pick **LTS**)
2. Run installer → accept defaults
3. Verify in terminal:
   ```bash
   node --version    # Should show v18+ or v20+
   npm --version
   ```

#### B. Install Android Studio
1. Download from https://developer.android.com/studio (~1 GB)
2. Run installer → accept all defaults
3. **First launch** — it will download the Android SDK (~3 GB, takes 15-30 min)
4. After SDK install completes, open **Settings → Languages & Frameworks → Android SDK**:
   - ☑ Check **Android SDK Platform 34** (or latest)
   - ☑ Check **Android SDK Build-Tools 34**
   - ☑ Check **Android SDK Platform-Tools**
   - ☑ Check **Android SDK Command-line Tools**
   - Click **Apply** → wait for install

#### C. Set Environment Variables (Windows)
1. Open **Start → "Edit environment variables for your account"**
2. Add new variable:
   - Name: `ANDROID_HOME`
   - Value: `C:\Users\YOUR_NAME\AppData\Local\Android\Sdk`
3. Edit **Path** → add: `%ANDROID_HOME%\platform-tools`
4. **Restart your terminal**

#### C. Set Environment Variables (macOS/Linux)
Add to `~/.zshrc` or `~/.bashrc`:
```bash
export ANDROID_HOME=$HOME/Library/Android/sdk     # macOS
# OR
export ANDROID_HOME=$HOME/Android/Sdk             # Linux
export PATH=$PATH:$ANDROID_HOME/platform-tools
```
Then: `source ~/.zshrc` (or restart terminal)

### 📲 Install on Your Phone

#### Method 1: USB Debugging (best — recommended) ⭐

**Setup phone (one-time):**
1. **Settings → About Phone**
2. Tap **"Build Number"** 7 times → "You are now a developer!"
3. **Settings → System → Developer Options**
4. Enable **"USB Debugging"**

**Install app:**
```bash
# Open Android Studio with the project
npx cap open android

# OR directly install via command line:
cd android
./gradlew installDebug    # Linux/macOS
.\gradlew installDebug    # Windows
```

In Android Studio:
1. Plug in phone via USB
2. Allow connection prompt on phone
3. Phone shows up in dropdown (top toolbar)
4. Click ▶ **Run** button
5. App installs and launches on your phone! 🎉

#### Method 2: Build APK & Sideload

```bash
cd android

# Linux/macOS:
./gradlew assembleDebug

# Windows:
.\gradlew.bat assembleDebug
```

APK is created at:
```
android/app/build/outputs/apk/debug/app-debug.apk
```

Transfer this file to your phone:
- Email it to yourself
- Upload to Google Drive
- Send via WhatsApp
- Copy via USB

On phone:
1. Tap the APK file
2. First time only: tap **"Settings"** → enable **"Install Unknown Apps"** for your file manager
3. Tap **Install** → done! 🎉

#### Method 3: Android Emulator

In Android Studio:
1. **Tools → Device Manager → Create Device**
2. Pick **Pixel 7** → click Next
3. Download a system image (Android 14)
4. Click Finish
5. Click ▶ next to the device to start it
6. Click ▶ **Run** to install your app on the emulator

## 7. CUSTOMIZE YOUR APP

### 🎨 Change App Name
Edit `capacitor.config.ts`:
```ts
appName: 'CalmNature',  // Change to your name
appId: 'com.calmnature.app',  // Reverse domain - must be unique
```
Then run: `npx cap sync android`

### 🖼️ Change App Icon
1. Generate icons using: https://romannurik.github.io/AndroidAssetStudio/icons-launcher.html
2. Download the zip → extract
3. Replace files in `android/app/src/main/res/mipmap-*/`
4. Run: `npx cap sync android`

### 🌟 Change Splash Screen
1. Create a 2732×2732 PNG with your logo (centered, dark `#050810` background)
2. Replace `android/app/src/main/res/drawable/splash.png`
3. Run: `npx cap sync android`

### 🎨 Change Theme Color
Edit `android/app/src/main/res/values/colors.xml`:
```xml
<color name="colorPrimary">#050810</color>
<color name="colorPrimaryDark">#050810</color>
```

### 🔊 Add More Sounds
Edit `src/data.ts` — add new birds to the `BIRDS` array or new environments to `ENVIRONMENTS`. Then `npm run build && npx cap sync android`.

## 8. PUBLISH TO GOOGLE PLAY (optional)

### Cost
- **One-time $25 fee** for Google Play Developer account

### Steps

#### A. Generate Signed APK/Bundle (one-time)

```bash
# Generate keystore (KEEP THIS FILE SAFE - never lose it!)
keytool -genkey -v -keystore calmnature-release.keystore \
  -alias calmnature -keyalg RSA -keysize 2048 -validity 10000
```

#### B. Configure signing
Create `android/key.properties`:
```properties
storePassword=YOUR_PASSWORD
keyPassword=YOUR_PASSWORD
keyAlias=calmnature
storeFile=../../calmnature-release.keystore
```

Edit `android/app/build.gradle` — add before `buildTypes`:
```gradle
def keystorePropertiesFile = rootProject.file("key.properties")
def keystoreProperties = new Properties()
keystoreProperties.load(new FileInputStream(keystorePropertiesFile))

android {
    signingConfigs {
        release {
            keyAlias keystoreProperties['keyAlias']
            keyPassword keystoreProperties['keyPassword']
            storeFile file(keystoreProperties['storeFile'])
            storePassword keystoreProperties['storePassword']
        }
    }
    buildTypes {
        release {
            signingConfig signingConfigs.release
            // ... existing config
        }
    }
}
```

#### C. Build the release bundle
```bash
cd android
./gradlew bundleRelease
```
Output: `android/app/build/outputs/bundle/release/app-release.aab`

#### D. Upload to Google Play
1. Sign up: https://play.google.com/console ($25)
2. Create app → fill out store listing (name, description, screenshots)
3. Upload the `.aab` file
4. Fill content rating questionnaire
5. Submit for review (~1-3 days)
6. **Your app is live on Google Play! 🎉**

## 9. TROUBLESHOOTING

### ❌ "command not found: npx" or "node"
**Fix:** Install Node.js. Restart terminal after install.

### ❌ "SDK location not found"
**Fix:** Create `android/local.properties`:
```
sdk.dir=C:\\Users\\YOU\\AppData\\Local\\Android\\Sdk     # Windows
sdk.dir=/Users/YOU/Library/Android/sdk                    # macOS
sdk.dir=/home/YOU/Android/Sdk                             # Linux
```

### ❌ "JAVA_HOME is not set"
**Fix:** In Android Studio: **File → Project Structure → SDK Location → Gradle JDK** → pick the embedded JDK.

### ❌ Build fails with "Gradle download stuck"
**Fix:** Use stable internet. Gradle downloads can take 10-20 min on first build.

### ❌ "Audio doesn't play"
**Fix:** Modern Android requires user gesture before audio. Just tap any mood card — audio will start. This is normal browser/Android behavior.

### ❌ "App crashes on launch"
**Fix:** Run `adb logcat | grep CalmNature` to see error logs. Most common: `npm run build` was forgotten before `npx cap sync`.

### ❌ "Phone not detected by Android Studio"
**Fix:**
1. Use a **DATA** USB cable (not charging-only)
2. Try a different USB port
3. Phone: **Developer Options → Revoke USB debugging authorizations** → reconnect
4. Install OEM USB driver for your phone brand

### ❌ "Failed to load resource: net::ERR_FILE_NOT_FOUND"
**Fix:** Run `npm run build && npx cap sync android` to ensure latest `dist/` is copied.
